# Solanalyze Showcase (Public)

Solanalyze is a forensic intelligence tool for analyzing wallet connections on the Solana blockchain.  
This repository is a **public showcase** and intentionally does **not** include full production implementation details.

🌐 **Live:** [solanalyze.com](https://solanalyze.com)

## Core Features (10 Analysis Modules)

| #  | Module                        | Description                                                                 |
|----|-------------------------------|-----------------------------------------------------------------------------|
| 01 | Direct Links                  | Direct SOL/token transfers between wallets                                  |
| 02 | Common Funders                | Shared funding sources across wallets                                       |
| 03 | Intermediate Paths            | Multi-hop indirect connections via third-party wallets                      |
| 04 | Token Launches                | Pump.fun / Raydium pool creation detection                                  |
| 05 | Funding Sources               | Traces origin of funds for each wallet                                      |
| 06 | DEX Activity                  | Jupiter, Raydium, Orca swap profiling                                       |
| 07 | **Deep Discovery**            | Counterparty scanning for hidden connections invisible to standard analysis |
| 08 | **Shared Token Activity**     | Cross-wallet token overlap detection with confidence scoring                |
| 09 | Wallet Labels                 | Custom human-readable names propagated across all sections                  |
| 10 | Network Graph                 | Interactive d3 force-directed 3D visualization                              |
